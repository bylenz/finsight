## Backend module map

```
backend/src/finsight/
  main.py                  # FastAPI app factory
  config.py                # pydantic-settings
  db.py                    # async engine + session + Base
  auth/                    # FR-AUTH-*
  expenses/                # FR-EXP-*
  budgets/                 # FR-BUD-*
  categories/              # taxonomy
  households/              # FR-MUL-03
  insights/                # FR-DASH-04 (Anthropic wrapper)
  common/                  # shared deps, errors, pagination
```

Each domain folder follows the same shape:

```
<domain>/
  router.py     # FastAPI routes
  service.py    # use cases / business logic
  schemas.py    # Pydantic v2 models for IO
  models.py     # SQLAlchemy ORM (when applicable)
```

## Data model (preliminary)

```
User(id, email, password_hash, created_at, household_id?)
Household(id, name, owner_id, created_at)
HouseholdMember(household_id, user_id, role)  -- owner | contributor | viewer
Expense(id, user_id, household_id, amount, currency,
        amount_base, category_id, description, occurred_at,
        is_business, source)                  -- manual | voice | csv
Category(id, name, icon, color, household_id?) -- null = global
Budget(id, household_id, category_id?, amount, currency, period) -- monthly
Alert(id, user_id, budget_id, type, triggered_at)               -- 80% | 100%
```

Constraints:

- `Expense.amount > 0`.
- `Expense.currency ∈ ('PEN', 'USD')` (extensible).
- `Budget.amount > 0`.
- Indexes on `(user_id, occurred_at)` and `(household_id, occurred_at)`.

## Endpoints (planned)

| Method | Path                | Description                                    |
| ------ | ------------------- | ---------------------------------------------- |
| POST   | `/auth/register`    | Register a user.                               |
| POST   | `/auth/login`       | Login, returns JWT.                            |
| GET    | `/expenses`         | List the authenticated user's expenses.        |
| POST   | `/expenses`         | Create an expense (auto-categorized).          |
| PUT    | `/expenses/{id}`    | Update an expense.                             |
| DELETE | `/expenses/{id}`    | Delete an expense.                             |
| GET    | `/budgets`          | List budgets.                                  |
| POST   | `/budgets`          | Create a budget.                               |
| GET    | `/dashboard`        | Current month summary.                         |
| GET    | `/insights/weekly`  | LLM-generated insight.                         |
| GET    | `/export/csv`       | Export expenses to CSV.                        |

Full live contract auto-generated by FastAPI at `/docs` (Swagger UI) and `/redoc`.

## Local deployment

`docker compose up` brings up:

- `db` — PostgreSQL 16 (persistent volume).
- `web` — FastAPI on `:8000`.
- `ui` — Streamlit on `:8501`.
- `adminer` — DB UI on `:8080`.
